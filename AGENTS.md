# Workspace Development Guidelines

## Mathematical Formula & Notation Standards
All documentation (Walkthroughs, Manifestos, Specifications, and READMEs) must adhere to clear, human-readable formula notation:
1. **Never use bare, unreadable LaTeX expressions alone** (e.g. `$\mathcal{F}_i = ...$`).
2. **Always include a clean visual text/ASCII box** representing the mathematical relationship with clear variable names.
3. **Include a structured breakdown table** defining every variable, its intuition, typical values, and a concrete example.
4. **Provide step-by-step numerical examples** so readers can verify calculations without specialized math software.
